# 📒 KGU-tracker (`MY UNIVERSITY`)

경기대학교(Kyonggi University) 전공 수업 및 학업 일정을 과목별로 체계적으로 관리하고, 여러 기기에서 실시간으로 동기화할 수 있는 개인용 웹 일정 관리 애플리케이션입니다.

🔗 **Live Demo:** [https://minyulee.github.io/KGU-tracker/](https://minyulee.github.io/KGU-tracker/)

---

## ✨ 주요 기능

### 1. 통합 대시보드 (`전체 일정` 탭)
모든 과목의 데이터를 종합하여 우선순위에 따라 세 가지 섹션으로 자동 분류해 보여줍니다.
* **오늘 해야 하는 일정:** 당일 마감되는 과제, 시험, 개인 할 일을 최상단에 표시합니다.
* **공지사항:** 전체 과목에서 `공지` 유형으로 등록된 중요 전달사항을 별도 섹션에 모아 한눈에 확인할 수 있습니다.
* **다가오는 일정:** 내일부터 7일 이내에 마감되는 이번 주 예정 일정을 날짜순으로 정렬하여 보여줍니다.
* **학업 현황 통계:** 전체 `남은 일정`, `이번 주 일정`, `완료한 일정` 개수를 실시간으로 집계합니다.

### 2. 과목별 탭 및 일정 관리
* 상단 탭을 통해 수강 중인 과목(인적 자원 관리, 소비자 행동, 회계원리, 핀테크 개론 등)과 교내 활동(`I.LAB` 등)을 자유롭게 추가하고 전환할 수 있습니다.
* 각 일정은 **과제 / 시험 / 공지 / 개인 할 일 / 기타** 카테고리로 구분되며, 상세 메모와 마감일을 기록할 수 있습니다.

### 3. 클라우드 실시간 동기화 및 오프라인 백업
* **Firebase Authentication & Firestore:** 이메일 계정 로그인을 통해 PC, 태블릿(iPad), 스마트폰 등 여러 기기에서 일정 데이터를 실시간으로 동기화합니다.
* **LocalStorage 자동 백업:** 브라우저 로컬 스토리지에 데이터를 이중 저장하여 안정성을 높였으며, 기존 로컬 데이터를 클라우드로 일괄 이관하는 기능을 지원합니다.

* **Backend / Cloud:** Firebase Authentication, Cloud Firestore
