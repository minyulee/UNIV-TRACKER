# 📒 UNIV-TRACKER

대학교 전공 수업 및 학업 일정을 과목별로 체계적으로 관리하고, 여러 기기에서 실시간으로 동기화할 수 있는 개인용 웹 일정 관리 애플리케이션입니다.

🔗 **Live Demo:** [https://minyulee.github.io/UNIV-TRACKER/](https://minyulee.github.io/UNIV-TRACKER/)

---

## ✨ 주요 기능

### 1. 통합 대시보드 (`전체 일정` 탭)
모든 과목의 데이터를 종합하여 우선순위에 따라 세 가지 섹션으로 자동 분류해 보여줍니다.
- **오늘 해야 하는 일정:** 당일 마감되는 과제, 시험, 개인 할 일을 최상단에 표시합니다.
- **공지사항:** 전체 과목에서 `공지` 유형으로 등록된 중요 전달사항을 별도 섹션에 모아 한눈에 확인할 수 있습니다.
- **다가오는 일정:** 내일부터 7일 이내에 마감되는 이번 주 예정 일정을 날짜순으로 정렬하여 보여줍니다.
- **학업 현황 통계:** 전체 `남은 일정`, `이번 주 일정`, `완료한 일정` 개수를 실시간으로 집계합니다.

### 2. 과목별 탭 및 일정 관리
- 상단 탭을 통해 수강 중인 과목(인적 자원 관리, 소비자 행동, 회계원리, 핀테크 개론 등)과 교내 활동(`I.LAB` 등)을 자유롭게 추가하고 전환할 수 있습니다.
- 각 일정은 **과제 / 시험 / 공지 / 개인 할 일 / 기타** 카테고리로 구분되며, 상세 메모와 마감일을 기록할 수 있습니다.

### 3. 클라우드 실시간 동기화 및 오프라인 백업
- **Firebase Authentication & Firestore:** 이메일 계정 로그인을 통해 PC, 태블릿(iPad), 스마트폰 등 여러 기기에서 일정 데이터를 실시간으로 동기화합니다.
- **LocalStorage 자동 백업:** 브라우저 로컬 스토리지에 데이터를 이중 저장하여 안정성을 높였으며, 기존 로컬 데이터를 클라우드로 일괄 이관하는 기능을 지원합니다.

- **Backend / Cloud:** Firebase Authentication, Cloud Firestore
- **Deployment:** GitHub Pages

## 🛠️ 서비스 개선일지 (Service Improvement Log)

> 실제 학사 일정을 관리하며 발견한 **사용자 불편(Pain Point)**을 정의하고, **정보 위계·UI 시인성·데이터 동기화 구조** 관점에서 고도화한 기록입니다.

### ① [UX/로직] 메인 뷰 정보 위계 재설계 및 일정 자동 분류
- **문제 인식 (Pain Point):** 전체 일정 화면에 모든 과목의 일정이 단순 나열되어, 당일 처리해야 할 긴급 일정과 이번 주 내에 대비해야 할 일정을 즉각적으로 구분하기 어려웠음.
- **해결 및 구현 (Action):** 날짜 데이터를 기준으로 `오늘 마감되는 일정`과 `7일 이내의 다가오는(이번 주) 일정`을 자동 필터링하여 상·하단 섹션으로 분리 출력하는 로직을 구현함.
- **기획적 기대 효과 (Result):** 앱 진입 직후 당일 우선순위 과업에 집중할 수 있도록 인지 부하(Cognitive Load)를 낮추고, 주간 학사 일정 누락을 방지하는 대시보드 가시성을 확보함.

### ② [UI 개선] 공지사항 섹션 배치 최적화 및 시각적 강조(Alert) 적용
- **문제 인식 (Pain Point):** 휴강, 보강, 시험 범위 변경 등 중요한 학사 공지가 일반 과제 목록에 묻혀 시인성이 떨어지고 확인을 놓칠 우려가 있었음.
- **해결 및 구현 (Action):** 전체 일정 탭의 레이아웃을 **[오늘의 일정 → 공지사항 → 다가오는 일정]** 순으로 재배치해 시선 흐름의 핵심 동선에 두고, 각 항목 앞에 굵기 없는(non-bold) 빨간색 느낌표(`!`) 아이콘을 적용함.
- **기획적 기대 효과 (Result):** 과도한 텍스트 강조 없이도 핵심 공지에 대한 즉각적인 주목도(Attention)를 확보하여 정보 전달 효율과 미니멀 UI의 균형을 달성함.

### ③ [데이터/인프라] 로컬 저장 한계 극복을 위한 Firebase 클라우드 동기화 및 이중 백업 구축
- **문제 인식 (Pain Point):** 초기 `LocalStorage` 단일 저장 방식에서는 PC와 태블릿·모바일 간 학사 일정이 연동되지 않으며, 브라우저 캐시 초기화 시 데이터가 유실될 위험이 존재했음.
- **해결 및 구현 (Action):** Firebase Authentication 및 Firestore를 연동해 계정별 실시간 다중 기기 동기화를 구현하고, 기존 로컬 데이터의 원클릭 클라우드 이관 및 로컬 이중 자동 백업 구조를 구축함.
- **기획적 기대 효과 (Result):** 강의실·도서관 등 이동 환경에서도 끊김 없는 멀티 디바이스 학사 관리 경험을 제공하고, 데이터 무결성과 안전성을 확보함.
